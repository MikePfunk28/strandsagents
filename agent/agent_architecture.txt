STRANDSAGENTS @AGENT COMPLETE SYSTEM ARCHITECTURE
==================================================

OVERVIEW:
---------
The @agent decorator system transforms StrandsAgents development by providing:
- Zero-boilerplate agent creation with a single decorator
- Built-in safe code execution sandbox
- Multi-agent workflow templates
- Intelligent agent chaining and registry
- Open source ready architecture for StrandsAgents contribution

CORE COMPONENTS:
----------------

1. @AGENT DECORATOR
   - Single decorator replaces 50+ lines of boilerplate code
   - Automatic model and agent creation
   - Global agent registry for discovery and chaining
   - Built-in code execution capabilities

2. ENHANCED SANDBOX EXECUTOR
   - Multi-language support (Python, JavaScript, Bash, PowerShell)
   - Persistent sessions with state management
   - Security features with timeouts and resource limits
   - Interactive REPL capabilities

3. WORKFLOW TEMPLATE SYSTEM
   - Pre-built templates for common scenarios:
     * Research Workflow (Plan -> Research -> Analyze -> Synthesize)
     * Code Development (Design -> Implement -> Test -> Deploy)
     * Data Analysis (Collect -> Clean -> Analyze -> Visualize)
   - Dependency management and topological execution
   - Agent routing and step chaining

4. MODEL SELECTOR
   - Intelligent model selection based on task requirements
   - Automatic detection of available Ollama models
   - Performance-based scoring and recommendations

AGENT CREATION PROCESS:
-----------------------

STEP 1: Decorator Application
   @agent(model_id="qwen3:8b", enable_code_execution=True)
   def my_agent(query: str) -> str:
       return f"Processing: {query}"

STEP 2: Agent Factory Processing
   - Parse decorator parameters
   - Create OllamaModel instance
   - Initialize Agent with tools and system prompt
   - Register in global AGENT_REGISTRY

STEP 3: Runtime Execution
   - Route queries to appropriate agents
   - Enable code execution when requested
   - Support agent-to-agent chaining
   - Execute workflow templates

AGENT SPECIALIZATION PATTERNS:
------------------------------

SIMPLE AGENT:
   @agent()
   def assistant(query): return response

CODE EXECUTOR:
   @agent(enable_code_execution=True)
   def coding_assistant(query): return execute_code(query)

TOOL SPECIALIST:
   @agent(tools=["http_request", "file_write"])
   def web_researcher(query): return research(query)

WORKFLOW PARTICIPANT:
   @agent(model_id="qwen3:8b")
   def workflow_agent(query): return process_workflow(query)

META AGENT:
   @agent(tools=["python_repl", "shell"])
   def meta_agent(query): return create_agents(query)
