# Strands Agents - Multi-Agent AI System

## Project Purpose
Strands Agents is a comprehensive multi-agent AI system that orchestrates intelligent agents to work collaboratively on complex tasks. The system provides a graph-based memory architecture, swarm coordination capabilities, and advanced analytics for optimizing agent performance and task execution.

## Core Value Proposition
- **Intelligent Agent Coordination**: Seamlessly coordinate multiple AI agents with different capabilities and models
- **Graph-Based Memory System**: Store and retrieve context-aware information using vector embeddings and semantic similarity
- **Production-Ready Architecture**: Scalable, secure, and performance-optimized system with comprehensive testing
- **Multi-Modal Capabilities**: Support for text, code, web scraping, file processing, and browser automation
- **Real-Time Analytics**: Monitor agent performance, detect patterns, and optimize swarm behavior

## Key Features

### Graph System (4-Phase Implementation)
- **Storage Layer**: Multiple backends (Parquet, JSON) with vector similarity search
- **Embedding Integration**: Auto-embedding generation with existing embedding systems
- **Enhanced Memory Graph**: Full swarm integration with MCP communication
- **Advanced Analytics**: Real-time monitoring, pattern detection, health assessment

### Swarm Coordination
- **Agent Registration**: Graph-based agent management and capability matching
- **Task Lifecycle Tracking**: Complete task management from assignment to completion
- **Memory Storage**: Context-aware information storage and retrieval
- **Performance Optimization**: Intelligent task-agent matching and coordination

### Multi-Agent Architecture
- **Base Assistants**: Research, creative, critical thinking, and specialist agents
- **Code Assistants**: Programming, debugging, and software development agents
- **Web Agents**: Browser automation, scraping, and web interaction capabilities
- **Security Layer**: Authentication, validation, and secure communication

### Production Features
- **Safe File Cleanup**: Intelligent file management with risk assessment
- **Security Hardening**: Input validation, access controls, audit logging
- **Performance Optimization**: Caching, async operations, memory efficiency
- **Comprehensive Testing**: Full test suite with 10+ test classes

## Technology Stack
- **Core Framework**: Strands Agents SDK with comprehensive tool ecosystem
- **AI Models**: Support for Anthropic, OpenAI, Ollama, and Azure AI services
- **Storage**: Vector databases (LanceDB, Qdrant), graph storage (Parquet, JSON)
- **Communication**: MCP protocol for agent-to-agent messaging
- **Web**: Flask/FastAPI frameworks with browser automation (Playwright)
- **Data Processing**: Pandas, NumPy, PyArrow for efficient data handling
